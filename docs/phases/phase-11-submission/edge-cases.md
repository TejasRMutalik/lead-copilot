# Phase 11: Edge cases

| Risk | What happens | Handling |
|---|---|---|
| Video over 3:00 | Fails a hard requirement | Rehearse with a timer; cut the intro first |
| Loom or Drive link private | Reviewers cannot open it | Test the link in incognito |
| AI rate limit while recording | Broken demo moment | Record after quota reset (about 1:30 PM IST) or keep a backup take; fallback chain helps |
| Secret committed earlier in history | Key exposed even if deleted later | Rotate the key; do not try to rewrite history at the last minute |
| Live URL breaks after submission | Bad first impression | No pushes to main after submitting unless it fixes a break |
| README claims something the app does not do | Caught in the interview | Every README claim must be clickable in the live app |
